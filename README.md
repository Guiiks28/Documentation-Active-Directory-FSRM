# Documentation-Active-Directory-FSRM
Ce dépôt contient la procédure pas à pas de mise en place d'un environnement de domaine Active Directory (AD DS) complet, incluant la gestion des utilisateurs par promotions, l'attribution des droits NTFS/Partages, l'application de GPO ciblées, ainsi que la gestion du stockage via FSRM (Quotas et Filtrage de fichiers).
